# Agent Counterfactual V3.2 Final Report

## Outcome

V3.2 passed every frozen feasibility gate and completed its downstream continuation and probe evaluation.

### Same-producer candidate generation

| Quantity | Result |
|---|---:|
| Attempted Qwen2.5-72B trajectories | 16 |

The frozen gate required at least 4/16 successes, at least three unique alternative deltas, and at least one success from each seed block. All three conditions passed. This resolves the counterfactual-support failure seen in V3.1 for dataclasses-jsonschema.

## Downstream evaluation

The candidate bank contained two successful Werkzeug states from V3.1 and nine successful dataclasses-jsonschema states from V3.2. They were evaluated on one and five real successor tasks respectively.

- 47 generated candidate–future combinations
- 6 historical-reference–future combinations
- 53 total continuation rows
- 23 candidate/historical probe-score rows
- zero fatal execution errors

All 23 probe-score rows passed. Consequently, these future-blind probes provide no within-anchor ranking signal: every candidate receives the same score and all probe/future Spearman correlations are undefined.

## Residual-state divergence

Although every generated candidate had passed its current task before propagation, its behavior in later repository states varied sharply:

| Later-state property | Generated candidates | Historical reference |
|---|---:|---:|
| State delta applies | 43/47 (91.5%) | 6/6 (100%) |
| Prior-task tests remain passing | 30/47 (63.8%) | 6/6 (100%) |
| Future gold patch is mergeable | 21/47 (44.7%) | 6/6 (100%) |
| Future already solved directly | 1/47 (2.1%) | 0/6 (0%) |
| Directly solved or gold-mergeable | 22/47 (46.8%) | 6/6 (100%) |

For dataclasses-jsonschema alone, gold-patch mergeability was 19/45 (42.2%). Individual current-success candidates ranged from 0/5 to 5/5 mergeable future tasks. Thus states generated by the same model for the same current task—and accepted by the same verifier—leave materially different future action spaces.

Among candidate/future pairs where the future gold patch remained mergeable, remaining patch churn was identical to the historical reference (delta 0 in all 21 comparisons). The observed debt is therefore primarily a **discrete compatibility failure**, not a gradual increase in patch size.

## Direct continuation and reranking

Only one generated candidate directly passed a future task without applying its future solution (1/47). This is a strict zero-adaptation compatibility measure, not a complete simulation of an agent solving the next task, so it should not be presented as the main continuation-value estimate.

The corrected reranking analysis shows:

- all probes tie at 1.0, so probe selection cannot distinguish candidates;
- probe selection obtains 0 direct-future success across the two anchors;
- oracle and minimum-patch tie-breaking obtain mean direct-future success 0.1 because one of the two equal-minimum dataclasses patches happens to be the sole direct success;
- random expected direct-future success is 0.0111 across anchors;
- with only two anchors, no selector-performance claim is statistically supportable.

## Interpretation

V3.2 establishes the minimum phenomenon needed for the paper:

> Current-task success and ordinary future-blind verification do not identify whether an agent leaves a state compatible with later work.

It does not yet establish a general critic or intervention result. The strongest current evidence is concentrated in one repository with nine same-producer counterfactual states. The next confirmatory experiment should expand the same construction to more anchors and evaluate an actual future-task agent from each state, rather than relying only on direct test compatibility and gold-patch transplantability.
