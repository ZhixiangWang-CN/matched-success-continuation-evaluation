# Third-party artifacts

Frozen records reference public open-source repositories and may contain issue
text, test patches, code patches, commit identifiers, or execution logs derived
from those repositories. These materials remain subject to the upstream
projects' licenses. Release metadata records the detected license for each
benchmark instance where available.

Detected SPDX families include Apache-2.0, BSD-2-Clause, BSD-3-Clause, MIT, and
MIT-0. Records marked `custom-check-github` require consulting the referenced
upstream repository at the recorded revision; that label is not a license.

No upstream repository checkout or model weight is redistributed here. Users
who reconstruct repository environments must obtain the upstream artifacts and
comply with their licenses independently.
