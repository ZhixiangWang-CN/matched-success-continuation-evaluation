# Claim–Evidence Ledger

Paper: *The Task Ends, the State Persists: When Success Is Not Sufficient for Persistent Agents*
Audit date: 2026-08-31
Scope: residual-state/continuation-value experiments only (R1–R16 in `ALL_EXPERIMENTS_RESULTS_SYNTHESIS.md`). The separate Epistemic Echo/provenance program is intentionally excluded from this paper ledger.

## Status vocabulary

- **VERIFIED**: the reported value matches a machine-readable result or can be recomputed directly from it.
- **VERIFIED—LIMITED**: numerically supported, but the stated limitation must accompany the claim.
- **STALE / CORRECT BEFORE USE**: a later/final artifact disagrees with the prose synthesis; use the corrected value below.
- **REPORT-ONLY**: the number is recorded in a report and backed by row artifacts, but this audit did not find a single authoritative aggregate field. It should be regenerated into a frozen summary before submission.
- **UNSUPPORTED AS PAPER CLAIM**: an experiment ran, but its design or gate does not identify the claimed quantity.
- **RETRACTED / INVALID ESTIMAND**: a number is arithmetically reproducible but the estimator does not identify the stated claim and must not appear in the paper.

Machine-readable results take precedence over prose reports. In particular, artifacts with `final_` or `analysis_corrected` in their names supersede earlier summaries.
